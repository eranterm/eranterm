EranTerm

A local-first desktop SSH manager for your servers: terminals, an SFTP file manager with drag & drop, live log tailing, and an AI assistant that only runs commands you approve.

Download latest release Read the help

Home

All your servers in one table: search, favorites, groups, availability checks.

File Manager

Browse, upload/download with drag & drop, folders as tar.gz, open a side terminal anywhere.

Terminal

Full xterm shell with AI command suggestions — nothing runs until you approve it.

Logs & Metrics

Live tailing with level colours and search, plus CPU/memory/disk alerts.

Scripts & Deployments

Reusable scripts with variables, broadcast to many servers, and deployment tracking.

No central backend

Runs locally. Optional Google sign-in backs your config up to your own Drive — nothing passes through our servers.
